## 1. สลายบทบาทตาม RACI

| สมาชิก | บทบาทในโครงการ | ความรับผิดชอบหลัก (A) ที่ส่งมอบแล้ว | สถานะหลังปิด |
|---|---|---|---|
| ปวริศ คูณศรี | Project Manager | Charter · EVM · CCB · Closure reports | ☐ ปลดจากบทบาท |
| พนาวุฒน์ อภิปสันติ | Tech Lead | Architecture · Branch protection · Release · Handover | ☐ ปลดจากบทบาท |
| ตรัยรัตน์ วงษ์สิทธิ์ | QA / Tester | Test plan · Test suites · UAT · Install verification | ☐ ปลดจากบทบาท |
| ทวีชัย ทิใจ | Developer | Bug fixes · Input validation · File I/O | ☐ ปลดจากบทบาท |

## 2. ข้อมูลผลงานจาก git (ตั้งต้นให้ประเมิน)

```bash
git shortlog -sne --all          # จำนวน commit ต่อคน
```

> ใช้ตัวเลขเป็นข้อมูลประกอบเท่านั้น — จำนวน commit ไม่เท่ากับคุณค่า (งาน review · ทดสอบ · ประสานงานไม่ปรากฏเป็น commit)
