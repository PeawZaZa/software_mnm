## 4. ROI

$$\text{ROI} = \frac{\text{Benefits} - \text{Cost}}{\text{Cost}} \times 100\%$$

| ช่วงเวลา | ผลประโยชน์สะสม | ROI |
|---|---:|---:|
| 1 ปี | 22,680 | **−55.3%** 🔴 |
| 3 ปี | 68,040 | **+34.2%** 🟢 |
| 5 ปี | 113,400 | **+123.7%** 🟢 |
| **Payback period** | 50,700 ÷ 1,890 บาท/เดือน | **26.8 เดือน** |

### ทำไมตัวเลขต่างจากตัวอย่างในใบงาน (+63.9% · คืนทุน < 8 เดือน)

ตัวอย่างในสไลด์ใช้ต้นทุน 16,100 บาท แต่โครงการนี้ใช้แรงงานจริง **169 ชม.** (45 issues × ~4 ชม.)
คิดเป็น 50,700 บาท — มากกว่า 3 เท่า ขณะที่ระบบเป็นโปรแกรม CLI สำหรับร้านค้าขนาดเล็ก
ผลประโยชน์ต่อปีจึงยังไม่พอคืนทุนในปีแรก **ทีมรายงานตามจริง แทนการปรับสมมติฐานให้ ROI เป็นบวก**
